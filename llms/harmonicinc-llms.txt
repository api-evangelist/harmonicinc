# Harmonic Inc.

> Harmonic Inc. (NASDAQ: HLIT) builds video streaming and virtualized broadband
> infrastructure. Its VOS®360 Media SaaS orchestrates the entire live and
> on-demand video pipeline (ingest, transcoding, packaging, encryption,
> playout, delivery), and its cOS broadband platform delivers virtualized DOCSIS
> and fiber access. The VOS 360 platform exposes a public REST API secured with
> OAuth 2.0 for integrating third-party CMS and media workflows.

## APIs
- [VOS 360 REST API Documentation](https://s3-us-west-1.amazonaws.com/vos360-public-api/index.html): REST API for managing assets, channels, services, live events, storage/packaging, DRM, graphics and jobs on the VOS360 media platform. Auth: OAuth 2.0 (Bearer).
- [VOS REST API Documentation](https://s3-us-west-1.amazonaws.com/vos-public-api/index.html): REST API for the VOS media processing software.
